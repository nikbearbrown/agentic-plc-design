# JP

## Executive summary

JP is the working panel builder and the expert for this course. This folder holds what is written for him specifically: [START-WINDOWS.md](START-WINDOWS.md), the step-by-step to get the lab tools running on Windows (through WSL Ubuntu) and do the labs, and the plan for the films that walk him through it. Nothing here has been run on Windows yet. JP's run is the first.
